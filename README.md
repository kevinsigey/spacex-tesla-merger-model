# SpaceX–Tesla Merger Model

The Excel valuation model behind **"The $3.5 Trillion Question"** (Research Desk, Kevin Sigey, October 2026), which values a hypothetical SpaceX–Tesla combination and compares it with the two companies' combined market value.

Paper: https://kevinsigey.github.io/portfolio/spacex-tesla-merger.html

## What is in the model

`SpaceX-Tesla-Merger-Model.xlsx` — the full workbook: segment-level build-ups for Tesla and SpaceX, scenario cases, and the probability-weighted expected value of the combined company (about $2,267B against a combined market value of about $3,538B at October 21, 2026 closes, in the paper's base framing).

## Date and status

Model built October 2026. It is published as the raw evidence behind the paper, exactly as built — inputs and assumptions are the paper's, stated there, and are not updated after publication.
